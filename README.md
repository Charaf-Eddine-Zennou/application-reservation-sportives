# Application de Réservation d’Activités Sportives

## Description
Cette application web fullstack permet aux utilisateurs de réserver des créneaux pour des activités sportives, avec une gestion complète des rôles (administrateur et utilisateur). Elle offre une interface intuitive et des fonctionnalités robustes pour gérer les réservations et les utilisateurs.

## Fonctionnalités
- Création et gestion des comptes utilisateurs avec rôles (admin, utilisateur)
- Réservation de créneaux pour différentes activités sportives
- Consultation et gestion des réservations
- Interface interactive et responsive grâce à React.js et Tailwind CSS
- Backend sécurisé et performant avec Spring Boot
- Stockage des données via PostgreSQL

## Technologies Utilisées
- **Frontend** : React.js, Tailwind CSS  
- **Backend** : Spring Boot  
- **Base de données** : PostgreSQL  
- **IDE / Outils** : VS Code, IntelliJ IDEA, GitHub
